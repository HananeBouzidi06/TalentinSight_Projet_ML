Le projet

TalentInsight Analytics transforme un projet de Machine Learning en dashboard interactif pour analyser des données RH : exploration, préparation des données, régression du salaire, classification de l'attrition et simulation.

💰 Prédire le salaire
Régression linéaire du salaire mensuel (MAD) d'un employé.
🎯 Détecter l'attrition
SVM, KNN, Decision Tree et Random Forest, avec un focus sur le Recall de la classe 1.
🧭 Éclairer les décisions
Analyser les données RH pour repérer les leviers (satisfaction, charge de travail…).

Technologies

Python · Flask · HTML5 / CSS3 / JavaScript · Pandas · NumPy · Scikit-learn · SciPy · Matplotlib / Seaborn · Joblib

Sans React, Node.js, Docker ni base de données. Les modèles sont entraînés une fois puis rechargés avec Joblib.

Le dataset

Le fichier rh_employes.csv contient {{ k.n_raw }} employés, soit {{ k.n_clean }} après suppression de {{ k.n_raw - k.n_clean }} doublons, avec {{ k.n_cols }} colonnes : profil (âge, genre, ville, diplôme), poste (département, niveau, expérience, ancienneté), charge et satisfaction, salaire mensuel en MAD et attrition.

Les graphiques et les modèles utilisent un échantillon stratifié de {{ k.n_sample }} employés.

Méthodologie

  • Le CSV original n'est jamais modifié.
  • Séparation train / test 80 / 20 stratifiée, avant d'apprendre le preprocessing (pas de data leakage).
  • Validation croisée avec preprocessing refait dans chaque fold.
  • Aucun GridSearchCV ni RandomizedSearchCV.
  • Tous les chiffres affichés sont calculés, rien n'est saisi à la main.
